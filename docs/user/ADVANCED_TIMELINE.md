# 联动剪辑、复合片段与参数动画

## 跨轨联动删除

时间线标题栏的“联动与复合”打开独立工具浮层。填写开始、结束秒数，或在播放头处使用“设为入点／设为出点”，再执行“删除区间并联动收拢”。右键片段也可以直接“删除并全轨联动收拢”。

这会在同一次编辑中裁切并收拢所有轨道、字幕、词级时间、标记、音量包络及多机位切点。受影响轨道已锁定时，操作会提示解锁并保持工程原样。一次撤销恢复整个操作。

## 按文本剪视频

在左侧“字幕”创作域，先完成识别、校对并提交字幕，再展开“按文本剪视频”。搜索转写文本，点击“定位”查看句子位置，或点击“试听”播放该句的范围。具有词级时间的识别结果还可点击“按词剪辑”，选择中文词或其他语言的词，并定位到其时间。没有词级时间的字幕仍可按句选择。

勾选句子或选择词后，面板显示合并后的范围与总时长，每段可单独试听，播放在范围终点自动停止。点击“预览删除影响”只会试算受影响的片段和字幕，不修改工程；点击“确认删除所选内容及画面”才会同步剪掉对应声音、画面和字幕，并收拢后续内容。取消预览不会产生编辑或撤销记录。多句或多词的相交区间只处理一次，整次确认仅提交一条 `transcript.delete` 命令，可一次撤销恢复各轨道、字幕和标记。

普通字幕文字编辑仍只修改字幕。存在锁定的受影响轨道时，需要先解锁；Agent 编辑租约期间不能执行删除。预览和确认前会等待本地编辑保存。预览后若工程版本、序列或选择发生变化，必须重新预览后确认；发生版本冲突时不会自动重试删除。

## 跨轨复合片段

在“联动与复合”浮层中勾选需要组合的片段。可以“选择播放头处图层”，再用“包含绑定图层”选入源视频及其跟随标题、贴纸等。创建后，复合片段可以整体移动、变速、添加变换和效果，也可以复制复用。

原来的轨道布局和内部内容保存在工程中。右键复合片段可“展开复合片段”，恢复到原轨道。已有整体音量、淡入淡出、音高、变速、定格或效果时，先还原这些整体处理再展开，避免丢失合成结果。

以下情况会明确拒绝创建：选区中夹着未选中的重叠图层；绑定源和跟随片段没有一起选入；存在独奏，或选中轨道／其总线启用了跨片段效果链。这些限制用于保留原来的图层顺序与声音处理结果。可以先关闭独奏、旁路轨道效果或扩大选区，再创建。

## 参数曲线

选中片段后，在参数关键帧区域选择不透明度、位置、缩放、旋转或音量。支持的调色和模糊数值参数也可动画化；效果参数绑定具体效果实例，调整效果顺序不会把曲线绑到另一个实例。

曲线图可拖动节点调整时间和值；可以选择多个节点，统一平移或缩放时间。缓动支持线性、缓入、缓出及三次贝塞尔，贝塞尔控制柄和数值控点均可编辑。每次提交走工程保存和撤销，预览与导出使用同一插值语义。

音频录制、分离和混音参见 [声音工作台](AUDIO_WORKBENCH.md)。多比例制作、多机位和跨软件工程交换参见 [制作版本与工程互换](PRODUCTION_VERSIONS_INTERCHANGE.md)。
